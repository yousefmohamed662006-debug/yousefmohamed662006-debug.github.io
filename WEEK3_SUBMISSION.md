## Assignment 2 · Decide Once: Build Your Identity Kit

### 1. Typography
* **Primary Font (Headings & Body):** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`
* **Rationale:** A single, neutral, highly legible sans-serif typeface prevents visual clutter and lets the numbers, code, and technical diagrams take center stage.

### 2. Color Palette

* **Main Color (`#1D4ED8`):** Confident royal blue used for interactive buttons, links, and key focus states.
* **Near-Black Text (`#0F172A`):** Deep slate providing high WCAG AAA contrast against light backgrounds without the harshness of pure `#000000`.
* **Near-White Background (`#F8FAFC`):** Soft off-white reducing eye strain and providing subtle warmth.
* **Single Accent (`#0F766E`):** Calm teal used sparingly for secondary tags and verified status indicators.

### 3. Brand Mark / Logo
* **Initials Mark:** `YM` / `YA` set in an uppercase badge with subtle border radius (`8px`) and 600 weight.
* **Wordmark:** `Yousef Abdelazem` in semibold 16px.

### 4. Two-Line Style Rule
> *"Use an 8px spatial grid with subtle border contours (`#E2E8F0`), zero decorative gradients, and strict monochrome hierarchy so that verified project metrics remain the loudest visual element on the page."*
