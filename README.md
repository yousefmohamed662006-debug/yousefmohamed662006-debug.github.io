This is the Week 4 "Empty but Live" starter for the FlyRank AI Fluency track.

## Stack
- HTML
- CSS
- GitHub Pages

## Deploy with GitHub Pages
1. Create a public GitHub repository named `yousefmohamed662006-debug.github.io`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the site to appear at `https://yousefmohamed662006-debug.github.io`.
7. Open the URL on your phone and take a screenshot.
